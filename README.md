# ساعت خورشیدی (Solar Clock Widget)

ویجت اندروید مدرن برای نمایش ساعت دیجیتال و اطلاعات خورشیدی تهران.

## ویژگی‌ها

- **ساعت دیجیتال** با طراحی تمیز و خوانا
- **طلوع و غروب** خورشید (محاسبه تقریبی بر اساس مختصات تهران)
- **طول روز** و مقایسه با فردا (↑ / ↓)
- **نوار پیشرفت روز** — نشان می‌دهد چه مقدار از روز گذشته است
- **تنظیم اندازه** هر بخش از طریق صفحه تنظیمات
- به‌روزرسانی دقیق هر دقیقه با AlarmManager

## ساختار پروژه

```
app/src/main/java/com/mehdi/analogclock/
├── ClockWidgetProvider.kt   # ویجت + رسم گرافیک
├── SettingsActivity.kt      # صفحه تنظیمات اندازه
└── SolarCalculator.kt       # محاسبه طلوع/غروب
```

## ساخت

```bash
./gradlew assembleDebug
```

یا از طریق GitHub Actions (هر push به `main` یک APK می‌سازد و Release می‌کند).
