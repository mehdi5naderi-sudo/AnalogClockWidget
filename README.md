# ساعت خورشیدی | Solar Clock Widget

ویجت اندرویدی ساعت با طراحی دایره‌ای ۲۴ ساعته که زمان فعلی، تاریخ شمسی و اطلاعات طلوع و غروب خورشید را در یک نمای خوانا نمایش می‌دهد.

## ویژگی‌ها

- صفحه‌ی ساعت دایره‌ای با نمایش چرخه‌ی ۲۴ ساعته
- ساعت دیجیتال بزرگ و تاریخ شمسی
- نمایش زمان طلوع و غروب خورشید و طول روز
- نمایش موقعیت زمان فعلی روی دایره و قوس روز
- تنظیمات ظاهری برای شخصی‌سازی نمایش ویجت
- طراحی گرافیکی اختصاصی با رسم در Canvas
- دریافت رویدادهای لازم برای تازه‌سازی ویجت پس از روشن شدن صفحه، بازگشت کاربر یا راه‌اندازی مجدد دستگاه
- پشتیبانی از دستگاه‌های Android 6.0 به بالا (حداقل SDK برابر 23)

> اطلاعات طلوع و غروب به موقعیت و محاسبات برنامه وابسته است؛ برای استفاده در شهرهای دیگر، دقت مکان و روش محاسبه را بررسی کنید.

## نصب و استفاده

1. آخرین APK را از بخش **Releases** مخزن دریافت کنید؛ اگر نسخه‌ای منتشر نشده، از بخش Actions وضعیت ساخت را بررسی کنید.
2. APK را روی دستگاه اندرویدی نصب کنید.
3. از صفحه‌ی ویجت‌های لانچر، «ساعت خورشیدی» را به صفحه‌ی اصلی اضافه کنید.
4. برای شخصی‌سازی، برنامه‌ی تنظیمات «ساعت خورشیدی» را باز کنید.

ممکن است لازم باشد برای به‌روزرسانی دقیق زمان، مجوز یا تنظیمات مربوط به آلارم‌های دقیق را در اندروید تأیید کنید. نام گزینه‌ها با توجه به نسخه‌ی اندروید و سازنده‌ی گوشی متفاوت است.

## ساخت پروژه

پیش‌نیازها:
- Android SDK
- JDK 17
- Gradle Wrapper موجود در مخزن

برای ساخت نسخه‌ی آزمایشی:

```bash
./gradlew assembleDebug
```

در ویندوز:

```bat
gradlew.bat assembleDebug
```

فایل APK آزمایشی معمولاً در مسیر زیر ساخته می‌شود:

```
app/build/outputs/apk/debug/
```

## ساخت خودکار

مخزن از GitHub Actions برای ساخت APK استفاده می‌کند. برای خروجی امضاشده، مقادیر محرمانه‌ی امضای اندروید باید در تنظیمات مخزن به‌درستی پیکربندی شده باشند. کلید خصوصی و رمزهای امضا را در کد یا README قرار ندهید.

## ساختار اصلی کد

```
app/src/main/java/com/mehdi/analogclock/
├── ClockWidgetProvider.kt
├── SettingsActivity.kt
└── SolarCalculator.kt
```

- `ClockWidgetProvider.kt`: رسم و مدیریت ویجت
- `SettingsActivity.kt`: صفحه‌ی تنظیمات
- `SolarCalculator.kt`: محاسبات مربوط به اطلاعات خورشیدی و تاریخ

## گزارش مشکل و مشارکت

برای گزارش خطا یا پیشنهاد، از بخش **Issues** استفاده کنید. برای مشارکت، تغییرات را در شاخه‌ای جداگانه آماده کرده و Pull Request ارسال کنید.

## مجوز

مجوز متن‌باز مشخصی در این مخزن اعلام نشده است؛ برای استفاده یا بازتوزیع کد، ابتدا از مالک پروژه اجازه بگیرید.
