# ساعت خورشیدی (Solar Clock Widget)

ویجت اندروید مدرن با طراحی دایره‌ای ۲۴ ساعته برای نمایش ساعت و اطلاعات خورشیدی تهران.

## ویژگی‌ها

- **دایره ۲۴ ساعته** — بالاترین نقطه = ۱۲ ظهر (حس خورشید)
- **ساعت دیجیتال** بزرگ در مرکز دایره
- **تاریخ شمسی** زیر ساعت (مثلاً ۸ مهر)
- **طلوع و غروب** در موقعیت دقیق روی محیط دایره
- **نشانگر متحرک** (نقطه) که با زمان فعلی روی دایره می‌چرخد
- **قوس روز** از طلوع تا غروب
- تنظیم اندازه ساعت، تاریخ و برچسب‌ها از صفحه تنظیمات
- به‌روزرسانی دقیق هر دقیقه با AlarmManager

## ساختار پروژه

```
app/src/main/java/com/mehdi/analogclock/
├── ClockWidgetProvider.kt   # ویجت + رسم گرافیک دایره‌ای
├── SettingsActivity.kt      # صفحه تنظیمات اندازه
└── SolarCalculator.kt       # محاسبه طلوع/غروب + تبدیل تاریخ شمسی
```

## ساخت

```bash
./gradlew assembleDebug
```

یا از طریق GitHub Actions (هر push به `main` یک APK می‌سازد و Release می‌کند).
