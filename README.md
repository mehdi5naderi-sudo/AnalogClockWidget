# ساعت و هوا | Clock & Weather Widget

ویجت اندرویدی عریض (تقریباً ۴×۳) برای نمایش ساعت دیجیتال، تاریخ شمسی و میلادی، طلوع و غروب خورشید، و پیش‌بینی آب‌وهوا (فعلی، ساعتی و روزانه).

## ویژگی‌ها

- ساعت دیجیتال بزرگ (۲۴ یا ۱۲ ساعته)
- تاریخ شمسی و میلادی + نام روز هفته
- زمان طلوع و غروب خورشید (محاسبه محلی)
- آب‌وهوای فعلی (دما، احساس، احتمال بارش)
- پیش‌بینی ساعتی (۴ تا ۱۲ ساعت آینده)
- پیش‌بینی روزانه (۳ تا ۷ روز آینده)
- تنظیمات کامل: نمایش/مخفی هر بخش، اندازه فونت، شفافیت، مکان، فاصله به‌روزرسانی
- منبع هوا: [Open-Meteo](https://open-meteo.com) (بدون کلید API)
- مکان پیش‌فرض: تهران (قابل تغییر در تنظیمات)
- حداقل Android 6.0 (API 23)

## نصب

1. آخرین APK را از **Releases** یا **Actions** بگیرید.
2. نصب کنید و ویجت «ساعت و هوا» را به صفحه اصلی اضافه کنید.
3. برای شخصی‌سازی، روی ویجت بزنید یا برنامه تنظیمات را باز کنید.

روی اندروید ۱۲+ ممکن است لازم باشد مجوز آلارم دقیق را در تنظیمات سیستم فعال کنید.

## ساخت

```bash
./gradlew assembleDebug
```

خروجی:
```
app/build/outputs/apk/debug/
```

## ساختار کد

```
app/src/main/java/com/mehdi/analogclock/
├── ClockWidgetProvider.kt   # رسم ویجت روی Canvas + زمان‌بندی
├── SettingsActivity.kt      # تنظیمات مفصل
├── SolarCalculator.kt       # طلوع/غروب + تبدیل تاریخ شمسی
└── WeatherData.kt           # Open-Meteo: فعلی / ساعتی / روزانه
```

## تنظیمات مهم

| بخش | گزینه‌ها |
|------|-----------|
| نمایش | شمسی، میلادی، طلوع/غروب، هوا، ساعتی، روزانه |
| تعداد | ساعات آینده، روزهای آینده |
| ظاهر | اندازه فونت‌ها، شفافیت، ۲۴ ساعته |
| مکان | عرض و طول جغرافیایی |
| هوا | روشن/خاموش، فاصله به‌روزرسانی |

## مجوز

مجوز متن‌باز مشخصی اعلام نشده؛ برای استفاده یا بازتوزیع با مالک پروژه هماهنگ کنید.
